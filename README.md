- My Cybersecurity Learning Roadmap

- 1. IT Foundations

Developing an understanding of computer systems, operating systems, hardware, and troubleshooting.

Topics:
- Computer hardware, CPU, RAM, and storage.
- Windows 11 and system configuration.
- Windows management and monitoring tools.
- Command-line fundamentals.
- Basic hardware and software troubleshooting.
- System performance and resource management.
- Virtual machines using VirtualBox.

- 2. Networking

Learning how computers communicate and how networks can be monitored, configured, and secured.

Topics:
- TCP/IP and network communication.
- IP addressing and MAC addresses.
- Common network ports and protocols.
- DNS (Domain Name System).
- HTTP and HTTPS.
- Network adapters and connectivity troubleshooting.
- Nmap and network scanning.
- Network enumeration and service discovery.

- 3. Linux and Kali Linux

Developing Linux skills for system administration and cybersecurity labs.

Topics:
- Linux commands and terminal navigation.
- Files, directories, and permissions.
- Users and groups.
- Processes and system monitoring.
- Package management.
- Basic shell scripting.
- Kali Linux in VirtualBox.
- Linux troubleshooting and security fundamentals.

- 4. Cybersecurity Fundamentals

Learning how systems, networks, and information can be protected against cyber threats.

Topics:
- The CIA triad: Confidentiality, Integrity, and Availability.
- Authentication and access control.
- Vulnerabilities and security weaknesses.
- CVEs (Common Vulnerabilities and Exposures).
- Common cyberattacks and attack methods.
- Password security and account protection.
- Security updates and patch management.
- Risk assessments and threat identification.
- Data protection and cybersecurity principles.

- 5. Red Team and Ethical Hacking

Exploring how security professionals identify and test weaknesses in systems with proper authorisation.

Topics:
- Reconnaissance and information gathering.
- Enumeration.
- Nmap scanning.
- Web application security.
- Common web vulnerabilities.
- Metasploit fundamentals.
- Privilege escalation concepts.
- Active Directory security fundamentals.
- Penetration testing methodology.
- Documenting findings and potential remediation.

I aim to practise these skills in authorised training environments, using platforms such as TryHackMe and other legal cybersecurity labs.

- 6. Blue Team and Defensive Security

Learning how organisations detect threats, investigate suspicious activity, and protect their systems.

Topics:
- Security monitoring.
- Windows system logs and event analysis.
- Threat identification.
- Incident response fundamentals.
- Malware and phishing awareness.
- Network traffic analysis.
- Vulnerability management.
- System hardening.
- Access control and authentication.
- Security policies and risk management.

- 7. Python Programming

Developing Python skills to understand programming fundamentals and eventually automate IT and cybersecurity tasks.

Topics:
- Variables and data types.
- Input and output.
- Conditional statements.
- Loops and control flow.
- Lists, dictionaries, and other data collections.
- Functions and exceptions.
- File handling.
- User input validation.
- Basic automation scripts.
- Simple IT and cybersecurity-related projects.

I am also working through Python learning material covering fundamentals, control flow, data collections, functions, and exceptions.
